# ruopengjia.github.io

Ruopeng Jia's personal website. The static site lives in `docs/`.

Preview the site from this checkout with:

```powershell
python -m http.server 8772 --bind 127.0.0.1 --directory docs
```

Open http://127.0.0.1:8772/ to review Home, About, Academic Projects,
News, and Gallery. The Gallery includes the original reading covers
and classical music pages.

The site uses relative paths so it can serve from a domain root or a
GitHub Pages project path. Configure a custom domain after the final
address is chosen.
